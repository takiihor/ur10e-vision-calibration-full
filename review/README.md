# Historical review records

The files in this directory describe the 10–11 November 2026 review of source
release `44f2f0aa` and the focused 36-test subset in
`results/final-13115877.txt`. They are retained for history.

They are **not** the manifest or test result for the current review-fix revision:

- `MANIFEST.sha256` and `CHANGED_FILES.json` describe the older 397-file source.
- `RELEASE_ARCHIVE.json` and `WORK.md` describe that older release.
- `results/final-13115877.txt` is a focused subset, not the full app or vendor
  suites.

Use the package-level `SOURCE_MANIFEST.sha256`, `CONTENTS.sha256`,
`provenance/`, and `RELEASE_NOTES.md` for the current revision.
